## 🎸 Instrument — Frontend Practice Clone

A responsive recreation of the [Instrument](https://www.instrument.com) agency 
homepage, built as part of the [Frontend Practice](https://www.frontendpractice.com/retired/instrument) 
challenge.

### 🛠 Built With
- HTML5
- CSS3
- Sass (SCSS)
- Mobile-first responsive design

### ✨ Features
- Mobile-first layout scaling across 3 breakpoints (mobile → tablet → desktop)
- Responsive hamburger dropdown nav (collapses to inline links on desktop)
- Autoplay muted looping hero video
- Alternating image/text sections using Flexbox
- Smooth hover transitions on buttons and nav links
- Custom `@font-face` variable font (Oswald)

### 🎯 What I Practised
- Sass architecture and CSS organization
- CSS `clamp()` for fluid typography
- Flexbox-based responsive layouts
- Mobile-first media query strategy
